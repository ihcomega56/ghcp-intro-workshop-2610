## この章でやること

GitHub で自分用の private リポジトリを作成します。作成時に GitHub Copilot cloud agent へプロンプトを渡し、アプリの雛形を作ってもらいます。Copilot が作成した PR をマージしたら、VS Code のターミナルでリポジトリを clone してローカルに取得します。

アプリのテーマは、全員共通で「カフェ注文シミュレーター」です。テーマ以外のプロンプトの書き方や、この後に追加する機能は自由に決めてかまいません。

## 手順

### リポジトリを作成し、cloud agent に雛形を依頼する

1. ブラウザーで [github.com](https://github.com/) を開き、サインインします。
1. 画面右上の **＋** ボタンをクリックし、**New repository** をクリックします。
1. 次のとおり入力します。
    - **Owner**: 自分のアカウント（講師から Organization の指定がある場合はそちら）
    - **Repository name**: 任意の名前（例: `cafe-order-app`）
    - **Visibility**: **Private** を選択
    - README、`.gitignore`、ライセンスの追加は不要です（Copilot に作ってもらいます）
1. **Prompt** 欄（Copilot でプロジェクトを始めるための入力欄）に、次のプロンプトを貼り付けます。内容は自由に書き換えてかまいません。

    ```text
    Python と Streamlit を使った「カフェ注文シミュレーター」の雛形を作ってください。

    - ローカル PC だけで完結して動作し、外部 API やデータベースは使わない
    - メニュー（商品名と価格）を3つほど表示し、カートに追加して合計金額を表示できる
    - まずは注文の基本的な流れだけを実装し、アプリ本体は app.py とする
    - 依存パッケージは requirements.txt に記載する
    - README.md に、仮想環境の作成からアプリの起動までの手順を Windows（PowerShell）と macOS の両方について書く
    - Python 向けの .gitignore を用意し、仮想環境のフォルダー（.venv）を含める
    - ソースコードコメントやUI上の文言などは日本語とする
    ```

1. **Create repository** をクリックします。
1. リポジトリが作成されると、Copilot が作業を始め、しばらくするとドラフトの PR が作成されます。リポジトリの **Pull requests** タブを開き、Copilot が作成した PR をクリックします。
1. PR 内の **View session** をクリックすると、Copilot が考えている内容や実行しているコマンドを確認できます。作業の完了まで数分かかるので、その間に次の「VS Code をアップデートする」を進めます。

### Copilot が作成した PR をマージする

1. ブラウザーで Copilot が作成した PR に戻り、Copilot の作業が完了していることを確認します。完了すると、Copilot からレビュー依頼が届き、PR のタイトルから `[WIP]` が外れます。
1. **Files changed** タブをクリックし、作成されたファイルを確認します。`app.py`、`requirements.txt`、`README.md`、`.gitignore` などが作成されているはずです。
1. **Conversation** タブに戻り、**Ready for review** をクリックしてドラフトを解除します。
1. **Squash and merge** をクリックし、続けて **Confirm squash and merge** をクリックします。
1. **Delete branch** をクリックして、作業用のブランチを削除します。
1. **Code** タブを開き、`main` ブランチにファイルが追加されていることを確認します。

### VS Code のターミナルで clone する

1. VS Codeに `Update` の表示がある場合は実行します。
1. ブラウザーでリポジトリの **Code** タブを開き、緑色の **Code** ボタンをクリックします。**HTTPS** タブに表示される URL をコピーします。
1. VS Code で **ファイル → 新しいウィンドウ** を開きます。
1. メニューの **ターミナル → 新しいターミナル** をクリックして、ターミナルを開きます。
1. ターミナルに次のコマンドを入力して、ホームディレクトリへ移動します。

    ```sh
    cd ~
    ```

1. 次のコマンドを入力して clone します。URL は、コピーしたものに置き換えます。

    ```sh
    git clone https://github.com/<ユーザー名>/<リポジトリ名>.git
    ```

1. 認証を求められた場合は、表示に従ってブラウザーで GitHub にサインインし、アクセスを許可します。パスワードやトークンをターミナルやチャットに貼り付けないでください。
1. VS Code のメニューで **ファイル → フォルダーを開く** をクリックし、clone したフォルダー（`~/<リポジトリ名>`）を選択して開きます。「このフォルダー内のファイルの作成者を信頼しますか？」と表示された場合は、**はい、作成者を信頼します** をクリックします。

## 余裕がある方向けの追加ワーク

1. Copilot が作成した PR の **View session** を開き、Copilot がどのような順番でファイルを作成し、どのようなコマンドで動作確認したかを読みます。
1. 同じテーブルの人と、cloud agent が作成した README やコードの書き方を見比べます。同じプロンプトでも結果が少しずつ違うことを確認します。
